ReSketch changelog
Newest commits first; one brief summary per commit.
Versions use major.minor.patch: +1.0.0 for very large updates, +0.1.0 for large updates, and +0.0.1 for fixes or minor changes.
About and --version show the build commit; Arch Git packages also include the commit count and hash.

1.2.9 - 2026-10-16
Initialized KDE's embedded icon fallback so app controls keep their icons when external icon themes are missing, while respecting the selected desktop icon theme.

1.2.8 - 2026-10-16
Added a default-on system colors toggle; disabling it enables Breeze Light/Dark selection across the app, with saved preferences and matching theme menu actions.

1.2.7 - 2026-10-16
Used Chromium's headless display backend for the release startup check in CI containers without a display server.

1.2.6 - 2026-10-16
Fixed the Arch release startup crash (close symbol missing) by retaining CEF ahead of libc in the load order; added a packaged-app startup check before publishing releases.

1.2.5 - 2026-10-16
Kept the floating-mode canvas filling all four frame edges after vertical layout changes, parent resizing, and window resizing.

1.2.4 - 2026-10-16
Declared Vulkan headers as a build dependency for clean Arch installations and release builds.

1.2.3 - 2026-10-16
Fixed Git checkout ownership checks in the Arch release containers.

1.2.2 - 2026-10-16
Added separate automatic CEF and Qt WebEngine Arch package builds and GitHub releases, pinned to the triggering commit with checksums and version verification.

1.2.1 - 2026-10-16
Added shared smooth scrolling and inertia settings for Figma and the app UI; fixed swipe input after switching tabs and kept desktop blur behind loading screens when sidebars use the canvas backdrop.

1.2.0 - 2026-10-16
Added finger-following sidebar tab swipes and overview card pinch-out; restored canvas pinch zoom, added inertial scrolling including Home sidebars, and updated CEF build instructions.

1.1.0 - 2026-10-16
Added trackpad pinch-to-overview from empty Figma sidebar space, with finger-following scale and movement, reversible progress, and smooth release.

1.0.20 - 2026-10-16
Removed multi-second Linux copy/paste stalls by waking Chromium for native clipboard events instead of waiting for polling intervals.

1.0.19 - 2026-10-16
Added adjustable floating sidebar shadow transparency and strength.

1.0.18 - 2026-10-16
Made Home sidebars opaque when using the canvas backdrop, preserving desktop backdrop transparency.

1.0.17 - 2026-10-16
Fixed canvas transparency behind docked sidebars and added canvas backdrop blur and opacity sliders for docked and floating sidebars.

1.0.16 - 2026-10-16
Fixed task manager CPU and memory readings using Chromium task memory metrics and renderer CPU clocks, with one-second updates and sampling only while the window is open.

1.0.15 - 2026-10-16
Fixed Enter and keypad Enter activation of the focused icon picker, color picker, and action buttons in the tab group popup.

1.0.14 - 2026-10-15
Redesigned the tab group popup with a live preview, clearer actions, keyboard focus cycling, picker shortcuts, and name validation.

1.0.13 - 2026-10-15
Removed canvas edge cropping and the page-color workaround. Hide native Figma scrollbars at renderer startup instead; changing visibility reloads file tabs and is deferred for sleeping tabs.

1.0.12 - 2026-10-15
Matched hidden canvas scrollbar edges to the current Figma page background, removing gray bottom and right strips and updating the fill live.

1.0.11 - 2026-10-15
Kept Home on the file browser when opening Figma documents, preventing editor navigation and repeated file tabs.

1.0.10 - 2026-10-15
Restored native layer drag/drop, applied floating sidebar settings without reloading files, and hid canvas scrollbar tracks live in floating mode.

1.0.9 - 2026-10-14
Fixed CEF paste freezes by dispatching native Linux events safely, and restored Figma access to installed fonts and the local font helper.

1.0.8 - 2026-10-14
Fixed native file-picker filters to include MIME types and Chromium's expanded image extensions, with an All files fallback.

1.0.7 - 2026-10-14
Fixed comment typing and shifted symbols, native-window canvas cursors, floating comment overlays, titlebar autohide, and automatic application of canvas scrollbar preferences.

1.0.6 - 2026-10-14
Clipped overflowing comment pins and collaborator markers around floating sidebars, restored Figma custom cursors, and added a system-cursor preference.

1.0.5 - 2026-10-14
Kept live overview browsers at native pixel density to prevent blurry card opening and Figma canvas shifts, while retaining the 30 fps preview limit and card-quality slider.

1.0.4 - 2026-10-14
Fixed stalled overview previews, reduced live-preview rendering to 30 fps with optional card-resolution textures, and kept comment pins behind floating sidebars.

1.0.3 - 2026-10-13
Renamed the CEF branch to resketch-cef and updated the Arch package source.

1.0.2 - 2026-10-13
Kept Home loaded while opening files in bursts, connected the embedded DevTools frontend, discarded cancelled exports without leaving a pending download, matched Slides sidebars to Design, and smoothed browser/UI scrolling.

1.0.1 - 2026-10-13
Restored the custom tab task manager and removed the Chromium native task-manager prototype.

1.0.0 - 2026-10-13
Migrated the browser engine to CEF with GPU texture rendering, a separate subprocess helper and an independent persistent profile while retaining the Kirigami tab UI.

0.3.7 - 2026-10-13

0.3.6 - 2026-10-13
Added a toggle to hide Figma scrollbars in floating sidebar mode while retaining scrolling.

0.3.5 - 2026-10-13
Fixed floating sidebar canvas-mask artifacts after native layout changes and kept the comments panel inside its floating bounds.

0.3.4 - 2026-10-13
Added an adjustable floating sidebar margin in Appearance settings.

0.3.3 - 2026-10-13
Restricted floating sidebars to Figma file pages and restored the thin navigation rail divider.

0.3.2 - 2026-10-13
Made floating sidebars overlay a full-width native Figma canvas with correct rendering and pointer coordinates, and outlined the complete sidebar.

0.3.1 - 2026-10-13
Kept floating sidebar transparency inside the rounded surface, restored canvas-colored margins and combined the navigation rail with the left panel.

0.3.0 - 2026-10-13
Added optional floating Figma sidebars, with adjustable corner radius and the existing desktop/canvas transparency controls.

Themed Figma's loading bars, file controls, sidebar labels and notification popup using KDE colors.
