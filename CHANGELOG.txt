ReSketch changelog
Newest commits first; one brief summary per commit.
Versions use major.minor.patch; Arch Git packages also include the commit count and hash.

0.2.0 - Unreleased
Made overview Left and Right navigation continue across row boundaries while preserving selection behavior.
Made Shift+Arrow selections accumulate; plain arrows replace the selection, and mouse clicks or Escape clear its tint.
Removed the automatic selection tint from the focused overview card and its collapsed group.
Restored the blue overview border only on the focused tab, keeping keyboard navigation and multi-selection tinted.
Changed overview keyboard focus to a selection tint and added Shift+Arrow range selection, including collapsed groups.
Added this commit changelog and consistent version reporting in About, --version, and Arch packages.
Fixed fullscreen autohide controls, reduced the toolbar reveal zone, and refined its slide easing.
Fixed whole-window blur coverage when entering fullscreen or resizing.
Added selected-tab tints, Shift range selection, Shift+Alt toggles, and dragging selected tabs together into and out of groups.
Added arrow-key overview navigation and Enter to open cards or expand and collapse groups.
Added a saved toolbar configuration with visibility checkboxes, drag and arrow reordering, and optional Export History, Settings, Task Manager, and Developer Tools buttons.
